# Предсказание стоимости поездки в сервисе такси (Taxi Fare Prediction)

Учебный проект для проведения код-ревью и отработки практик MLOps. Представляет собой пайплайн машинного обучения для предсказания стоимости поездок такси с использованием алгоритма Gradient Boosting.

## Структура проекта
```text
lesson-08-code-review/
├── data/
│   └── uber.csv          # Датасет с историей поездок
├── src/
│   ├── data.py           # Загрузка и разбиение данных
│   ├── features.py       # Инженерная генерация признаков (Feature Engineering)
│   ├── model.py          # Класс модели машинного обучения
│   └── main.py           # Основной скрипт запуска пайплайна
├── tests/
│   └── test_data.py      # Модульные тесты
├── requirements.txt      # Зависимости проекта
└── README.md             # Документация проекта


## Системные требования
- Python 3.10 или выше
- Менеджер пакетов `uv` (рекомендуется) или стандартный `pip`
## Инструкция по установке и запуску
### Способ 1: С использованием современного менеджера uv (Рекомендуется)
Клонируйте репозиторий и перейдите в папку проекта:
```bash
cd lesson-08-code-review
```
Создайте изолированное виртуальное окружение:
```bash
uv venv
```
Установите зависимости из файла `requirements.txt`:
```bash
uv pip install -r requirements.txt
```
Запустите пайплайн обучения модели:
```bash
PYTHONPATH=. uv run python src/main.py
```
### Способ 2: Классический способ через venv и pip
Клонируйте репозиторий и перейдите в папку проекта:
```bash
cd lesson-08-code-review
```
Создайте виртуальное окружение:
```bash
python -m venv .venv
```
Активируйте виртуальное окружение:
**Linux / macOS:**
```bash
source .venv/bin/activate
```
**Windows (PowerShell):**
```powershell
.venv\Scripts\Activate.ps1
```
Обновите pip и установите зависимости:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```
Запустите проект:
```bash
PYTHONPATH=. python src/main.py
```
## Ожидаемый результат
